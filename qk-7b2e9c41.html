QuillKit documentation

QuillKit is a lightweight toolkit for building structured documents.

Overview

QuillKit provides a small, composable API for turning plain text sources into structured documents. It ships with a template engine, a layout pipeline, and exporters for HTML and PDF.

The project follows a documentation-first design: every public function is covered by examples, and the command line interface mirrors the Python API one to one.

Feature overview

  • Template engine with inheritance, slots, and named blocks.
  • Incremental builds that re-render only changed sources.
  • Built-in exporters for standalone HTML and print-ready PDF.
  • Pluggable renderers for custom output formats.
  • A command line interface for builds, previews, and validation.

Installation

QuillKit is published on PyPI and can be installed with pip:

python -m pip install quillkit

The core package has no compiled dependencies. Optional extras provide syntax highlighting and PDF export:

python -m pip install "quillkit[highlight,pdf]"

After installation, verify that the command line entry point is available:

quillkit --version

Quick start

Create a source file named intro.qk and render it with the default template:

from quillkit import Document, render

doc = Document.from_file("intro.qk")
html = render(doc, template="default")
doc.write("intro.html", html)

The same operation is available from the command line:

quillkit build intro.qk --template default --output intro.html

Configuration reference

QuillKit reads an optional quillkit.toml file from the project root. The most common settings are listed below.

SettingDefaultDescription
templatedefaultTemplate used when none is specified on the command line.
output_dirsiteDirectory that receives rendered documents.
incrementaltrueRe-render only sources whose inputs changed.
strictfalseTreat template warnings as build errors.

Command line interface

  • quillkit build renders one or more source files.
  • quillkit preview starts a local preview server with live reload.
  • quillkit check validates templates and links without writing output.
  • quillkit init creates a starter project layout.

Frequently asked questions

Can QuillKit be embedded in another application?

Yes. The renderer is a plain function that accepts a Document and returns a string, so it can be embedded in scripts, notebooks, or web services.

Does QuillKit require a network connection?

No. All processing happens locally; templates and assets are resolved from the file system.

How are template errors reported?

Errors include the template name, line number, and a short excerpt of the offending markup.
